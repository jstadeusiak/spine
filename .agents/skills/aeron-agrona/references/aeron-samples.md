## Basic publication, polling, fragmentation and file transfer

A successful `offer` appends to a transport log. It does not by itself prove remote receipt, application effects or Archive completion. Retain the same bytes across transient negative results, and explicitly handle closed/max-position results. Allocate the buffer and assemblers before the loop; callbacks borrow their buffers. A fragment limit counts fragments, not complete application messages.

## Throughput variants, claims, vectors, IPC and spy

Choose `ExclusivePublication` for a single owner; it removes concurrent-publisher arbitration but remains single-thread confined. `tryClaim` avoids the staging-buffer copy only for a message no larger than `maxPayloadLength()`. Commit or abort promptly, without disk/network waits inside the claim. Vectored `offer` gathers into Aeron’s term buffer; it avoids constructing a combined staging array, not every copy. Keep the same benchmark load while comparing these alternatives.

## Round-trip latency and aggressive driver configuration

RTT uses a timestamp written by the sender and returned unchanged, so subtraction occurs on one host’s monotonic clock. It is not cross-host one-way latency. Warmup precedes HdrHistogram capture. Separate the application’s idle strategy from the driver’s sender/receiver/conductor strategies; the aggressive examples consume cores and can hurt latency when oversubscribed.

## Archive recording, fixed replay, replay/live recovery and replication

The useful recorder boundary is: attach recording, successfully publish, then wait until the recorder reaches the returned transport position. That proves Archive recording progress under its configured sync policy, not power-loss survival. Recording/session IDs, start positions and physical frame alignment matter. Remote clients must use Archive protocol queries or a remote authority contract rather than reading another host’s local RecordingPos counter.

## Cluster deterministic service, topology and snapshot repair

Committed callback replay must reproduce application state and generated messages from logged inputs. Use Cluster time, logged configuration and deliberate iteration/snapshot order; avoid wall-clock/random external inputs in the reducer. Client-session egress is a separate transient effect. ## Applying these patterns to Spine

- Reuse aligned Agrona buffers, primitive maps, confined exclusive publications and fresh idle strategies. Use controlled ABORT to retain input until a downstream transition succeeds; keep terminal failures explicit.
- Measure each boundary: optional complete proposal capture, Cluster admission, direct canonical publication, Archive recording completion and application cursor. None of the transport-only throughput examples proves the entire pipeline’s latency or durability.
- Current Spine output is a direct IPC publication. Its consumer catalog uses Archive protocol positions and supports separate-driver UDP replay; the service output fence remains local. Cross-host multicast is proposed, with distinct-host qualification still required. Keep Cluster/service/Archive colocated, record outgoing UDP through LOCAL/spy, and preserve Archive protocol authority and targeted replay for remote consumers.
- Native UDP multicast needs an actual supported network, assigned data/control groups and ports, reachable interface, membership/routing/TTL and MTU policy. Same-host IPC or local spy avoids the receive network path. MDC is a unicast alternative when native multicast is unavailable.
- Flow control is part of the receiver contract. Choose whether all, some tagged, or only faster receivers constrain sending; keep the recorder critical and optional slow consumers able to recover from Archive. Spy connection/flow-control behavior must be tested rather than inferred from the benchmark’s spiesSimulateConnection setting.

The C/C++ sources and build files also appear in the coverage manifest. Their substantive individual patterns and launch/configuration scripts are catalogued by the companion `samples-launchers.md` reference.
